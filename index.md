# Jarvis

Jarvis es un asistente personal de uso privado. Lo desarrolla y lo usa una sola persona, el titular de la cuenta de GitHub villalbanietor22, para ayudarle a gestionar su propio correo de Gmail desde su computadora.

Jarvis no es un servicio publico: no tiene usuarios externos y no se vende ni se distribuye.
