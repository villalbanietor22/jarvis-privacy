# Política de privacidad de Jarvis

Última actualización: 13 de noviembre de 2026.

Jarvis es un asistente personal de uso privado. Solo lo usa su desarrollador, el titular de la cuenta de GitHub villalbanietor22, con su propia cuenta de Google. No tiene otros usuarios.

## Qué datos usa

Con la autorización del titular, Jarvis accede a su cuenta de Gmail mediante la API de Gmail: mensajes, etiquetas, borradores y configuración básica del correo.

## Para qué los usa

Jarvis usa esos datos únicamente para cumplir las instrucciones del titular, por ejemplo leer, resumir, organizar, redactar o enviar sus correos. El contenido puede procesarse con el modelo de inteligencia artificial que usa el asistente (Claude, de Anthropic) solo para ese fin.

## Almacenamiento y terceros

Las credenciales de acceso se guardan cifradas en la computadora del titular. Jarvis no tiene servidores propios, no vende datos, no los usa para publicidad y no los comparte con terceros, salvo el procesamiento descrito arriba.

El uso de la información recibida de las APIs de Google cumple con la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

## Cómo revocar el acceso

El acceso se puede revocar en cualquier momento desde la página de permisos de la cuenta de Google: myaccount.google.com/permissions

## Contacto

Para cualquier duda, abre un issue en el repositorio villalbanietor22/jarvis-privacy de GitHub.
